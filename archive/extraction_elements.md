# Extraction Elements

This file is the master question bank for later PDF-by-PDF extraction. Each row is an atomic spreadsheet-friendly element. Unless a project-specific spreadsheet says otherwise, use these status codes in cells: `ND` for not discussed, `DU` for discussed but unclear, and `OCR_NEEDED` when the PDF text cannot be reliably read. For every non-`ND` answer, record page number, section heading, and a short quote in evidence fields if available.

| Question ID | Topic category | Question | Answer type | What to extract if discussed | Suggested keywords or sections to search | Expected frequency across documents | Notes for consistent coding |
|---|---|---|---|---|---|---|---|
| meta_doc_type_001 | document metadata | What type of district document is this PDF? | categorical | Code CBA, employee handbook, salary schedule, benefits guide, policy manual, MOU, tentative agreement, settlement summary, board policy, or other. | title page, table of contents, agreement, handbook, policy manual, salary schedule, memorandum | likely frequent | Use the document's own title when possible. If multiple types appear, code the primary type and note secondary content. |
| meta_effective_dates_002 | document metadata | What school years or effective dates does the document cover? | date or short text | Extract start date, end date, school years, and any extension period. | effective, duration, term of agreement, school year, fiscal year, July 1, June 30 | likely frequent | If the document is undated, code `DU` and quote any clues from the title or footer. |
| meta_bargaining_unit_003 | document metadata | Which employee group or bargaining unit is covered? | short text | Extract covered groups, such as teachers, certificated staff, instructional employees, counselors, librarians, substitutes, or all employees. | recognition, bargaining unit, unit members, teachers, certificated, instructional employees | likely frequent | If the document covers all employees, note whether teacher-specific provisions can be separated. |
| meta_document_scope_004 | document metadata | Does the document state that it is binding, advisory, summary-only, or not a contract? | categorical | Extract whether it is binding agreement, policy, handbook guidance, summary of changes, tentative, or non-contractual. | agreement, handbook is not a contract, tentative agreement, summary, policy | likely frequent | Especially important for handbooks and settlement flyers. |
| meta_text_usability_005 | document metadata | Is the PDF text extractable enough for reliable coding? | categorical | Code usable, partially usable, scanned/OCR needed, or corrupted; note pages affected. | pdf text extraction, OCR, blank output, image-only | occasional | Use `OCR_NEEDED` for topic answers if extraction prevents assessment. |

| meta_state_law_citations_007 | document metadata | Which state laws or statutes are cited? | short text | List statute names, code sections, or rule references exactly as they appear in the document. | state statute, education code, code section, administrative rule | likely frequent | Quote citations as they appear; do not look up the full text. Code ND if meta_cites_federal_law_008 is no. |
