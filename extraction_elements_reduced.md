# Extraction Elements

This file is the master question bank for later PDF-by-PDF extraction. Each row is an atomic spreadsheet-friendly element. Unless a project-specific spreadsheet says otherwise, use these status codes in cells: `ND` for not discussed, `DU` for discussed but unclear, and `OCR_NEEDED` when the PDF text cannot be reliably read. For every non-`ND` answer, record page number, section heading, and a verbatim quote (not a paraphrase) in evidence fields if available, including the verb that governs the provision (e.g., shall, must, may, shall not, is entitled to). For every non-`ND`, non-`not_applicable` answer, also code a `modality` value of `mandatory`, `discretionary`, or `prohibited` based on that governing verb; see `llm_agent_prompt.md` for the full coding rules and examples, including the agent/subject "watch out" rule for clauses about excluded classifications such as principals or administrators. If an answer or evidence quote includes a position, classification, or salary-schedule code or acronym (such as `ET-15`, `EG-09`, or `BA+30`) that would be unclear to a general reader, spell out or define the term using the document's own definition (e.g., from a recognition article, definitions section, or salary schedule legend) if the document gives one; if the document does not define the term, note that it is undefined.
